## 🚀 How to Enable GitHub Pages (1-Minute Setup)

To publish these pages live on GitHub Pages (so you can use the links for Google Play Console App Content submission):

1. **Push this repository** to GitHub.
2. Open your repository page on GitHub.
3. Click **Settings** (top navigation tab).
4. In the left sidebar, click **Pages** (under *Code and automation*).
5. Under **Build and deployment**:
   - **Source:** Select `Deploy from a branch`.
   - **Branch:** Select `main` (or `master`) and folder `/ (root)`.
6. Click **Save**.

Your website will be live at:  
`https://<your-github-username>.github.io/<your-repo-name>/`

## 📱 App Highlights
- **DCA Gold Accumulation Simulation:** Model long-term physical gold accumulation.
- **Physical Gold Portfolio Tracker:** Monitor holdings, buy-back valuations, and P&L.
- **Dynamic Bid-Ask Spread Engine:** Realistic shop buy vs sell pricing.
- **Dual Language & Unit System:** English (USD / Troy Oz) & Vietnamese (VND / Chỉ / Lượng).
- **Privacy-First:** All transaction data remains 100% on the user's device.
